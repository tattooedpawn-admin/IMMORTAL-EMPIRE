# IMMORTAL EMPIRE: THE MCGOLDRICK LEGACY

**A browser-playable 3D empire-building game prototype.**

Immortal Empire is an evolving game universe centered on business development, property, character progression, missions, and the connected *Immortal Empire: Bloodlines* storyline. The long-term direction is a cinematic 3D open world, with a separate Unreal Engine 5 production track.

## Current playable build

**Fifth Street — WebGL prototype v1.3** is a small, low-poly technical demonstration. It includes a 3D district, third-person player, mobile touch movement and camera, interactive business locations, cash/day progression and local progress saving. It is **not** yet a photorealistic AAA game. Bloodlines combat is **not** implemented.

### Controls

| Platform | Controls |
| --- | --- |
| Android/mobile | On-screen movement control, swipe to orbit camera, tap **Interact** near a location |
| Desktop | WASD to move, drag to orbit camera, E to interact |

## Play on GitHub Pages

After publishing, open the repository's GitHub Pages address. To enable hosting:

1. Place `index.html`, `.nojekyll`, and this README at the repository root.
2. Open **Settings → Pages** in GitHub.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose **main** and **/(root)**, then **Save**.
5. Wait for GitHub to show the published HTTPS address.

GitHub Pages hosts the static browser game; it does not run Unreal Engine projects. This prototype is designed to use no external JavaScript CDN.
