# Contributing

IMMORTAL EMPIRE is currently a privately controlled game project in a public repository. The repository is published for demonstration and testing, not as an open-source contribution invitation.

Please open an issue to report a reproducible bug or suggest an improvement. Include the device, browser, steps to reproduce, expected behavior and actual behavior.

Do not submit pull requests, game assets, likenesses, music, or other copyrighted material without prior agreement with the project owner. No contribution rights or licenses are granted by this document.
